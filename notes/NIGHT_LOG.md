# Ночная лаборатория: улучшение построения кандидатов

Протокол: LocBench, официальный GT, сплит по sha1(instance_id) на dev (~50%)
и holdout. Итерации только на dev; holdout + Lite + Verified — один раз в
конце для победителей. Метрики: ceil@50/@100 (все gold в кандидатах),
строгая Acc@5/@10 порядка кандидатов (без LLM), per-file recall@50.

Базовая точка (рецепт статьи): union(граф-BM25 80, граф-grep 30, BM25 15).

## Свип 1 (запущен ~01:55)

Идеи: explicit paths из issue; RM3-расширение запроса; BM25 по путям;
recency-prior (FixCache/AmaLgam); нормировка co-change по частотам;
темпоральный граф по всем файлам; сглаживание по каталогам; RRF-фьюжн
5 списков; демоция тестов/доков; 3-шаговое распространение.
